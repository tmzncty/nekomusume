## Two bugs this slice found in its own work

1. **Prefix-match trap.** `"iterations":1000` is a substring of
   `"iterations":10000`, so the default-value assertion passed even under the
   mutant that reported the ceiling instead of the default. The
   `MN_default_wrong` mutant survived on exactly this, which is how it was
   found. Every numeric assertion now anchors on the following delimiter, with a
   comment recording why.
2. **Wrong delimiter when parsing `p95_ns`** (splitting on `}` instead of `,`)
   made the field unparsable; corrected.

Both corrections changed the test files, so the whole probe was re-run against
the corrected content and the pre-probe snapshots diffed clean against the
committed files. The only run reported here is that final one.

The single invalid construction is `EM_no_median_field` (dropping the
`,"median_ns":{}` fragment changes the format string's argument count, so it
does not compile). Recorded as invalid, not as an equivalence.
