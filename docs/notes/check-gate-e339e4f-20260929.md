## 85461's conditions → evidence

1. **One shared nonce/replay state, derived bounds.** `seal_probe` / `open_probe`
   call the session's `seal` / `open`, so the nonce manager and replay window are
   shared. `probe_records_share_the_single_nonce_and_replay_state` checks
   consecutive sequences across a probe and a Data record, and that a replayed
   probe is refused on both paths. The bounds come from
   `PLPMTUD_MAX_MTU − ip_udp_header_bytes − RECORD_SEAL_OVERHEAD`, which gives
   1422 / 1402; `probe_bounds_are_derived_from_max_mtu_per_family` checks them. The
   values are in D067, and D031 gains only a cross-reference; its own text is
   unchanged.
2. **Per-family pre-authentication bound; flag off never reaches `open_probe`.**
   `open_datagram(record, None)` is exactly `open_unreliable`.
   `flag_off_datagram_path_never_reaches_the_probe_bound`: a 1251-byte probe record
   is refused with the flag off, and the refusal happens before authentication (the
   same record then opens with the flag on). `family_bounds_are_not_interchangeable`
   covers the per-family bound.
3. **After authentication, only a zero-padded kind 6; uniform rejection.**
   - `probe_path_admits_only_a_zero_padded_kind_6_probe` refuses Data (1300 and
     100 bytes), ACK-shaped, nonzero padding, short, long and wrong-version inputs
     through `open_probe`, each with the identical `SessionRejected`. The session
     stays usable afterwards.
   - The flag-on 1300-byte Data record is refused in
     `flag_off_datagram_path_never_reaches_the_probe_bound` and in the cross-crate
     `every_other_real_process_kind_is_refused_by_the_probe_path`, which uses the
     real `ProcessMessage::Data` encoder.
4. **`seal_probe` checks kind 6 before sealing.** The same tests assert that
   `seal_probe` refuses every non-probe plaintext.
5. **Layout agreement across crates.** neko-crypto cannot depend on neko-session.
   `probe_seal_layout.rs` in neko-carrier proves that real encoded `PmtuProbe`s at
   each family's maximum pass the probe seal, and that real Data / `PmtuProbeAck`
   do not.
