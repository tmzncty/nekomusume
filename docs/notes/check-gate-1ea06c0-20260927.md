## The six equivalences (all measured in a draft worktree, then removed)

- `IR_capacity_off`: `Vec::with_capacity(0)` is a preallocation hint only; the
  sealed first message measured 224 bytes with and without the mutant.
- `RR_rest_len_check_off`: the negotiation bytes after the binding are never read
  downstream; consistency is enforced by the prologue binding. Measured: the
  round trip still succeeds with the check removed, and a responder configured
  with a different-length binding still fails.
- `RF_bound_off`, `FN_n_zero_off`, `FN_finished_off`: dropping these guards
  leaves every reachable outcome unchanged. Measured: an oversized message and a
  truncated response are still rejected. An honest responder writes an empty
  final payload (so `n != 0` cannot arise in-process), and both responder entry
  points refuse an empty scope.
- `RR_scope_len_zero_off`: same reason - the responder's `scope_len == 0` arm is
  unreachable because no constructor emits an empty scope.

The scratch experiments were removed and the worktree md5-verified against the
