schema field (`nekomusume.reliable-udp-lab.v1`), yet that string appeared **only in
the implementation** - no test asserted it. The existing lab assertions live in the

`recovery` sub-objects except `delivered`/`duplicates`/`conflicts`;
`unauthenticated`, `recv_rejected`, `manager_switch`, the `manager_active_path` key
name and the long `manager_switch_scope` text.

scenario's whole line byte for byte (which is where the impairment fields the clean

rather than a shared one); and a third, differently-valued invocation proving

pinned scenarios were verified deterministic (three identical runs each) before
being asserted verbatim**, since the command drives a real UDP loopback.
