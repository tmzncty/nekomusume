## Two holes the probe caught (round 1), and their fixes

1. **Empty payloads were not pinned as empty.** For the two field-less envelopes I had
   asserted only up to `"seq":0`, so **appending a field survived**. The needles now run
   to the trailing brace (`"seq":0 }`), which catches an appended field as well as a
   renamed/re-valued one.
2. **`r9_udp_post_return_residual` has two emit sites with byte-identical text, and both
   fire in this test.** A text assertion cannot tell which emitter produced a line, so
   mutating either site left the other's correct line satisfying the assertion - all
   eight mutants on that event survived. The fix pins the occurrence **count**
   (measured at 2 from the test itself) alongside the text. This is the **third**
   instance of the dual-emitter class (`udp_authenticated`, `endpoint_a_confirmed`,
   now this).
