## Behavioural contract and evidence

- `set_probe_df(&UdpSocket)` sets `IP_MTU_DISCOVER` or `IPV6_MTU_DISCOVER` =
  `PROBE` for the socket's own family, and returns kernel errors unchanged.
- On non-Linux it returns `ErrorKind::Unsupported`. Slice 3 must treat any error as
  fatal when the flag is on, and never fall back to a fragmentable socket
  (condition 3).
- `kernel_path_mtu` is diagnostic only. PLPMTUD decisions never read it.
- Real-socket tests:
  - v4 and v6 read-back via `getsockopt` asserts `PROBE`, after first asserting the
    default is not `PROBE`;
  - on a v6 socket, the v4-level option is left untouched;
  - a kernel refusal (IPv6 option on an IPv4 socket) is surfaced;
  - the MTU query fails on an unconnected socket and reports at least 1280 once the
    socket is connected.
- IPv6 × 1278 remains N/A in the future matrix (D067: IPv6 below its 1280-byte
  minimum link MTU loses its addresses).
