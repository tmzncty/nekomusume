## What was removed, and on what evidence

**Removed (7):**

- `MemoryPairError::{MessageTooLarge, QueueFull, Closed, PeerClosed, ArithmeticOverflow}`.
  Only two variants of this type are ever constructed (`InvalidLimits` in `new`,
  `StatePoisoned` in `lock`); the type is referenced nowhere outside `neko-carrier`;
  D054 already states `MemoryPairError` is not part of the generic Carrier
  contract; and the five removed names are identical to `UdpError`'s variants in
  the same file, i.e. copy-paste residue never trimmed. The pair has no
  datagram-size, queue-capacity, close or peer-close semantics at this boundary -
  those arrive as `CarrierError`, which is what `MemoryEndpoint` operations return.
- `PathError::{ValidationDomain, ActivePathRequired}`. The path state machine
  raises `ValidationRequired` and `ActivePathConflict` instead (the `Activate` gate
  returns `ActivePathConflict` when a path is already active). The machine has no
  "domain" notion beyond one doc comment about evidence domains.

**Kept (4), with reasons recorded in the note:**

- `PmtuSendOutcome::Sent` — a *send outcome* enum and the return type of
  `Plpmtud::on_emsgsize`; a "sent" success arm is a natural member of that shape, so
  removing it would silently narrow the type's meaning rather than delete noise.
  Looks like an unimplemented intent, not dead code.
- `StreamState::Reset`, `RuntimeError::Deadline`, `LedgerError::ContextMismatch` — all
  in `neko-session`, a spec'd crate inside this guard's restricted zone.
  `StreamState` already models half-close; `IdleTimeout` is in use beside `Deadline`;
  and `docs/spec/m0-session-state.md`'s context-matching rules make a
  context-mismatch error plausible.

## Verification performed before removing

None of the six candidate enums has any `impl` block (so no `Self::Variant` can
belong to them), none is glob-imported, none is aliased (`use ... as`), and none is
`#[non_exhaustive]`; all eleven candidates had zero references in any form across
`crates/**`. On the docs side, neither `docs/spec/m0-session-state.md` nor
`docs/spec/m2-plpmtud.md` names any of these variants as a contract - the only
documentation hits came from the note itself, which this commit updates.

## Known consequence, stated explicitly

Removing a `pub` variant is a **breaking API change** for any external consumer
that matches it. This narrows the published surface of `neko-carrier`. The
justification is that no in-workspace code and no in-repo document used them, and
the maintainer authorised the removal.
