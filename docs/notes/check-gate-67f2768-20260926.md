## The two HANGs

`UN_nonblock_a` / `UN_nonblock_b` set `set_nonblocking(false)`, so the existing
test's first `recv_datagram()` blocks forever instead of returning would-block.
Recorded as **kills of the bounded-work property**, kept separate from the
assertion kills: the test detects the regression by not terminating. This slice
therefore used the timeout-capable runner throughout
(`/tmp/mutprobe_to.py`, `MUT_TIMEOUT=40`); the earlier no-timeout incident is why
that runner exists.

## The three equivalences

- `UN_bind_a_any`: binding the socket to `UNSPECIFIED` instead of `LOCALHOST`.
  Verified **empirically** rather than assumed - the mutant was applied to the
  draft and the existing loopback assertion still passed. After `connect` to a
  loopback peer the kernel selects 127.0.0.1 as the local address, so
  `local_addr()` reports a loopback address under either bind.
- `UCE_poisoned_io`, `UD_close_poison_kind`: both only rename the error carried
  by the `map_err` closure on a poisoned endpoint mutex. Nothing panics while
  holding that mutex, so it can never be poisoned and the closure never runs.
