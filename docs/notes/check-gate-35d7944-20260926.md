`record_datagrams` loop once per unit of an arbitrarily large external counter
delta, so `datagram_huge_delta_emits_bounded_events` never terminates. The first
probe run used a runner without a per-run timeout and stalled on this mutant for

1. killed the specific PIDs (the python runner, its cargo child, and the test

2. restored the probe worktree to pristine before doing anything else;
3. identified the stalled mutant from the log's last line plus the mutant list;
4. re-ran the remaining 11 mutants through a timeout-capable runner

The hang is recorded as a **kill of the bounded-work property**, kept separate
from the assertion kills rather than folded into them: the test does detect it,
by not terminating. Every subsequent run used the timeout-capable runner.
