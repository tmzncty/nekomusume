## What slice 3 is

Both ends must pass `--plpmtud`. The client sets DF (`PMTUDISC_PROBE`) first and
fails closed on any error; after the data exchange it runs the bounded probe loop
(binary search 1278/1298 → 1500, 2 attempts per size, 32 probes per generation,
≥50 ms spacing, ack wait = negotiated `--duration`). Only an authenticated
`PmtuProbeAck` bound to (generation, id, size) raises the confirmed size; timeouts
and EMSGSIZE only lower the search bound; probe loss is never congestion loss or
retransmission. The server answers a probe with the fixed 22-byte ack and stays
reachable until its application deadline. The periodic family is pinned by test to
never reference the probe path. Experimental values per the administrator-approved
D067 list; default behaviour and D031 unchanged; not release policy.
