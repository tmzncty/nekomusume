## Method notes, disclosed

- **Instrumentation repeatedly landed in non-statement positions.** Two attempts
  inserted dump statements inside multi-line structures (`ReadyServer { .. }` and
  `assert!` argument lists), which does not compile - and the failure surfaced as the
  compiler echoing source text, so a `grep` "hit" looked like output. Finding a
  function's end by **brace counting also fails**, because string literals contain
  `{`/`}` (e.g. `format!("{}")`). The working approach was to anchor on a specific
  line already known to be a complete statement in that test.
- **Refs were counted with bare names.** The JSON form is `\"event\":\"X\"` with
  backslashes, so a *quoted* grep misses occurrences; only bare-name counting is
  reliable here.
