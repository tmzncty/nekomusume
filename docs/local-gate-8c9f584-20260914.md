`crates/neko-cli/tests/probe.rs`. No production Carrier/Session/crypto/wire semantics changed and no
new dependency was added.

- **BLOCKER-GATE-001** — `--scenario` uses a dedicated optional parser. Plain `lab` and
  `lab --json` keep the legacy socket-free fixture; unknown, duplicated or value-less scenarios
  fail with exit `2` before any socket or identity side effect. The previous required-value parse
  call made every no-scenario `lab` invocation fail.
- **H-R8-001** — the receiver commits the authenticated outer AEAD sequence as the recovery packet
  number, and only after `open()` succeeded and the inner record is structurally valid Data.
- **H-R8-002** — cwnd admission applies to every initial packet, including one the fault seam later
  suppresses; the Session byte offset commits only after admission; retransmission consults
  admission and counts refusals.
- **H-R8-003** — PTO is deadline-driven from the current RTT estimate and PTO count on a
  deterministic logical clock.
- **H-R8-004** — success counters increment only after the operation succeeded; the JSON separates
  offered/admitted/wire-sent/suppressed, ACK emitted/wire-sent/suppressed/applied/rejected, PTO
  due/fired, retransmit attempts/wire-sent/refusals, deliveries/duplicates/conflicts, application
  bytes, newly lost, remaining in-flight, manager switch state and cleanup.
- **H-R8-005** — a bounded settlement phase drains recovery or reports an explicit partial outcome,
  so `ok=true` cannot be emitted with unfinished delivery.
- **M-R8-006** — the warm-TCP signal is reported as a manager-level decision with an explicit scope
  note; this command opens no TCP socket.
